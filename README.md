# 🎮 ByteAdventure

**ByteAdventure** es un proyecto desarrollado en **Unity** orientado a la creación de una aventura interactiva, aplicando conceptos de programación, diseño de videojuegos y desarrollo de mecánicas mediante C#.

El proyecto forma parte de mi aprendizaje y práctica de desarrollo de software y videojuegos.

---

## 🕹️ Descripción

ByteAdventure es una aventura desarrollada con Unity en la que se trabajan diferentes conceptos relacionados con:

- Programación en C#
- Desarrollo de mecánicas de juego
- Gestión de escenas
- Interacción con objetos
- Organización de proyectos Unity
- Diseño de niveles
- Gestión de assets
- Lógica de juego

El proyecto irá evolucionando conforme se incorporen nuevas funcionalidades.

---

## 🛠️ Tecnologías utilizadas

- **Unity**
- **C#**
- **Git**
- **GitHub**
- **Visual Studio / Visual Studio Code**
